# Diario de aprendizaje – UD3: Apache

## 1. ¿Qué he aprendido?

En esta unidad he aprendido qué es Apache y para qué sirve, además de conocer un poco su historia y su importancia dentro de los servidores web.

También he aprendido a instalar y configurar Apache en Ubuntu, crear una página web personalizada y hacer que se pueda acceder a ella mediante una dirección configurada en el servidor.

Otra cosa que he aprendido ha sido a proteger una página web mediante usuario y contraseña, para que no pueda acceder cualquiera.

Por último, he aprendido qué es HTTPS, por qué es importante para la seguridad de las páginas web y cómo configurar un certificado SSL/TLS para poder acceder a nuestra página de forma segura.

## 2. Actividades realizadas

Durante esta unidad hemos realizado varias prácticas relacionadas con Apache.

Primero hicimos una actividad de introducción a Apache, donde investigamos qué es, para qué sirve, su historia y algunas alternativas que existen. También tuvimos que documentar la información y explicar los resultados de las actividades realizadas.

Después realizamos la práctica de configuración de Apache. Instalamos el servidor en Ubuntu y creamos una página web personalizada. También configuramos un VirtualHost para poder acceder a nuestra página utilizando un nombre propio.

Además, realizamos una práctica de seguridad en la que configuramos la autenticación mediante usuario y contraseña. Para comprobar que funcionaba, probamos el acceso desde otro equipo, utilizando la máquina virtual de una compañera.

Por último, hicimos la práctica de HTTPS, donde activamos los módulos necesarios de Apache, generamos un certificado autofirmado y configuramos el servidor para permitir el acceso mediante HTTPS. También configuramos una redirección para que al entrar mediante HTTP se pasara automáticamente a HTTPS.

## 3. Dificultades encontradas

Esta unidad me ha parecido una de las más prácticas y también una de las que más dificultades me ha dado.

Al principio tuve que acostumbrarme a trabajar con los archivos de configuración de Apache y a utilizar los comandos de Ubuntu para instalar y modificar las diferentes opciones del servidor.

También tuve algunos problemas al configurar el VirtualHost y la autenticación, pero fui solucionándolos poco a poco.

En la práctica de HTTPS tuve un error con la ruta del certificado, porque había escrito mal una parte de la dirección del archivo. Después de revisarlo y corregirlo conseguí que funcionase correctamente.

Aun así, realizando las pruebas y comprobando los resultados conseguí terminar las actividades.

## 4. Valoración personal

En general, esta unidad me ha parecido bastante interesante porque hemos podido trabajar directamente con un servidor web y comprobar cómo funciona.

Lo que más me ha gustado ha sido poder crear mi propia página web y después acceder a ella desde otro equipo. También me ha parecido interesante aprender a proteger el acceso mediante contraseña y configurar HTTPS para que la conexión sea más segura.

Aunque algunas partes me han resultado complicadas, creo que he aprendido bastante y ahora entiendo mejor cómo se instala y configura un servidor web.

Me ha servido para conocer herramientas y configuraciones que antes no sabía utilizar y para tener una idea más clara de cómo se puede poner en funcionamiento y proteger una página web.
