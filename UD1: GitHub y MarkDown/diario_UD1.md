# Diario de aprendizaje – UD1: GitHub y Markdown

## 1. ¿Qué he aprendido?

En esta unidad he aprendido a utilizar GitHub y a conocer algunas de sus funcionalidades. Al principio no sabía muy bien cómo funcionaba ni para qué servían algunas de sus herramientas, pero poco a poco he ido entendiendo mejor cómo se utiliza para guardar proyectos, trabajar con repositorios y compartir nuestro trabajo.

También he aprendido a utilizar Markdown, que es un lenguaje bastante sencillo para crear documentos. He visto cómo poner títulos, texto en negrita, cursiva, enlaces, imágenes, listas y tablas, entre otras cosas.

Además, he conocido herramientas para generar documentación de proyectos y he aprendido la importancia de mantener nuestros repositorios organizados, seguros y accesibles.

## 2. Actividades realizadas

Durante esta unidad hemos realizado diferentes prácticas para aprender a utilizar GitHub y Markdown.

Primero hicimos un trabajo de introducción a GitHub, donde investigamos sus funcionalidades, para qué sirve y conceptos como los *merges* y los *pull requests*.

Después realizamos una práctica de Markdown en la que tuvimos que crear un documento siguiendo un ejemplo del profesor. Con ella pude practicar los diferentes elementos que se pueden utilizar en un archivo `.md`.

También hicimos una práctica en GitHub creando un documento llamado `GitHub.md`, donde explicamos algunas de sus funciones y los pasos para utilizarlas.

Otra actividad consistió en evaluar y utilizar un generador de documentación para un proyecto que habíamos realizado el curso pasado. En mi caso, trabajé con el proyecto de Gestión de Biblioteca y pude comprobar cómo se genera la documentación del código.

Por último, realizamos una práctica sobre seguridad y accesibilidad en el control de versiones, también utilizando el proyecto de Gestión de Biblioteca. En ella trabajamos la importancia de mantener los proyectos y su documentación bien organizados y protegidos.

## 3. Dificultades encontradas

Al principio algunas cosas de GitHub me resultaban un poco difíciles, porque no estaba acostumbrada a utilizar todas sus herramientas y había conceptos que no conocía.

Con Markdown tampoco sabía muy bien cómo se escribían algunas cosas, pero después de hacer la práctica fui entendiendo mejor su funcionamiento.

Otra parte que me resultó algo más complicada fue la de generar la documentación de un proyecto, ya que había que localizar los archivos y saber dónde se encontraba la documentación generada.

Aun así, realizando las actividades y siguiendo los pasos poco a poco he conseguido entender mejor cómo funciona todo.

## 4. Valoración personal

En general, me ha parecido una unidad bastante útil, porque he aprendido cosas que puedo utilizar en otros proyectos y trabajos.

Lo que más me ha gustado ha sido aprender a utilizar Markdown y conocer mejor GitHub, ya que me parece una herramienta muy útil para guardar y organizar los proyectos que vamos realizando durante el curso.

Creo que todavía tengo cosas que mejorar y aprender, pero ahora entiendo mucho mejor para qué sirve GitHub y cómo puedo utilizarlo. También me ha servido para darme cuenta de la importancia de documentar bien los proyectos y mantenerlos organizados.
